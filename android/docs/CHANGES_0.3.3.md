# SyncClipboard Android 0.3.3

## 文件通知

- 支持解析服务器 `latest_global` 中的 JSON 数组、对象和嵌套文件列表。
- 单文件通知直接显示完整文件名。
- 多文件通知标题显示文件数量，正文显示前 3 个文件名；超过 3 个时追加“等”。
- 展开通知最多显示前 8 个文件名。
- Android 中转文件连续到达时，会汇总当前全部待下载文件名，而不是只显示最后一个。

## 通知自动清理

设置页新增“临时通知保留时间（秒，0=不自动清理）”。

- 默认值：60 秒。
- 可设置范围：0–86400 秒。
- 应用于新文件、下载完成和文件发送结果通知。
- 前台常驻服务通知不会自动清理。
- 同类通知沿用固定通知 ID，新通知会替换旧通知，避免堆叠。

## 息屏省电模式

设置页新增“息屏省电模式”。启用后：

- 息屏时保留前台服务进程和常驻通知。
- 暂停本机 HTTP 监听，不接收 `/ping`、文字更新或文件通知。
- 暂停剪贴板监听、注册请求、文件上传和文件下载。
- 释放 CPU/Wi-Fi 唤醒锁。
- 亮屏后自动恢复 HTTP 服务、剪贴板监听和客户端注册。

## 桌面图标

- 只缩小自适应桌面图标的前景图形至原来的 72%。
- 不修改通知栏使用的 `ic_sync` 小图标。
