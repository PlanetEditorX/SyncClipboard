## v12 改了什么

只有一处：普通文件分支补一行**结束标记** `③ 文件同步结束：N 个`。

v11 上单纯复制几个文件时，日志停在最后一条 `OK 写入` 就没了，看不出是
正常跑完还是半路断掉（目录分支本来就有 `⑤ 同步结束`，文件分支漏了）。补上
之后两条路径的收尾形态一致，以后看日志不用再数行数猜。

## 日志在哪

```
release/dist/SyncClipboard/log/ios_shortcut.log
```

每个节点（含循环里每处理完一个文件）都会把累积后的完整日志整份推一次，所以
崩在哪一步，文件里就停在哪一条。手机「下载」里那份 `SyncClipboard-调试.log`
是尽力而为的副本，存不上不影响排查。

## 仍然存在的限制

- **空目录**建不出来（没有文件就没有落点），结尾会提示数量。
- 文件多时「每个文件一次下载 + 一次日志推送」，会慢。
- 多台电脑各登记了目录时无法合并清单，会明确提示「请分开同步」。
- 电脑端要 1.12.6 及以上才有 `prefix` 字段；更旧的版本会退回 `dir + "/"`
  拼接，多一个斜杠 iOS 会合并，层级仍然对。
